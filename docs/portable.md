# Project Neko 一期运行包

适用于 Windows 10/11 的64位电脑。无需安装MSYS2、Qt、OpenCV或Python；程序在本机进行识别，需要可用的摄像头。请先完整解压到有写入权限的文件夹，不要直接在压缩包中运行。

## 启动和操作

1. 双击 `StartNeko.cmd`，默认只显示机器人，不开启摄像头。
2. 右键机器人或托盘图标，勾选“开启手势互动”；需要观察识别结果时勾选“显示检测画面”。也可双击 `StartWithPreview.cmd` 同时开启两者。
3. 首次确认手出现时开心一次；张手左右挥动触发挥手回应；仅伸食指时进入食指跟随。
4. 用两指中点光标对准机器人头顶，光标变绿后捏合，提起并中低速移动；松开后放下。在其他位置捏住后移入头部不会补抓，需要先松开。
5. 光标紫色表示未确认捏合，绿色表示对准头顶，橙色表示已确认捏合；橙色不保证已经抓住机器人。
6. 右键菜单选择“退出”可关闭程序和摄像头。关闭检测窗口只停止显示；隐藏机器人不会自动关闭已开启的摄像头。

默认使用0号摄像头。若要选择其他设备，可在运行包目录的CMD中执行：

```bat
StartNeko.cmd --camera-index 1
```

摄像头默认不开启。请避免与独立预览、视频会议等程序同时占用同一摄像头，并检查Windows摄像头隐私设置。

## 本期效果与边界

- 2026-10-27用户已通过核心功能及切换流程的联调验收，中低速捏合拖动可用。
- 高速移动时仍可能偶发抓取中断，明确留到第二期优化。未统计成功率或延迟，不保证任意光照、距离和手部角度下都能稳定识别。
- 挥手、位置跟随和捏合拖动只接受单手。检测到多只手会中断单手交互。
- 短暂丢失时，食指跟随允许约1秒的位置预测；捏合拖动冻结位置，约0.5秒无有效测量后释放，两者策略不同。
- 当前捏合使用加权二维指尖距离，依赖手在画面中的方向；仍保留双阈值及连续帧确认。
- 摄像头归一化坐标映射到机器人所在屏幕的可用区域，检测预览窗口大小不决定控制范围。多显示器及不同DPI配置仍需额外实测。

## 文件与排查

- `neko_desktop.exe`、同目录DLL、`platforms`、`styles`、`qt.conf`：程序和运行依赖，请完整保留。
- `models`：两个ONNX模型及其许可证；移动整个文件夹时一并保留。
- `licenses`、`THIRD-PARTY-NOTICES.md`：第三方组件的版本、来源与随附许可证。
- `LICENSE-CODE.txt`：本项目原创代码的MIT许可证，第三方模型和库保留各自许可。
- `BUILD-INFO.json`、`SHA256SUMS.txt`：打包来源及文件校验信息。
- `source/ProjectNeko-source.zip`：本次应用源码和构建说明，不包含模型或第三方库源码。

桌面端通过Qt读取模型文件，再将原始字节交给OpenCV，因此模型所在目录可包含中文；该处理不改变模型内容、预处理、识别阈值或手势规则。

排查时在运行包目录执行：

```bat
StartNeko.cmd --camera --preview --vision-debug
```

数值日志写入同目录 `desktop-vision.log`，不保存摄像头图像；每次诊断启动覆盖旧日志。默认启动不写诊断日志。

如Windows提示缺少DLL，请重新完整解压，不要从其他安装目录随意混入不同版本的库。本运行包未制作安装向导，也不要求管理员权限；首次在其他电脑运行时仍需实际验证摄像头和系统兼容性。
